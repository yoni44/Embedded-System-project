Peer2Peer Communication Stack Project
Project Overview
This project is a Peer2Peer wireless communication application built for Atmel microcontrollers. It implements a network stack supporting secure message transmission using Atmel radio hardware. The software includes UART communication, security features, and routing functionalities.

Features
Peer-to-peer message sending and receiving over wireless network

UART interface for data input/output and debugging

Security mode with encryption enabled

Periodic data transmission using timers

Supports various Atmel microcontroller platforms (e.g., ATmega128RFA1, ATmega256RFR2)

LED indicators and button interfaces integrated via hardware abstraction layer

Low-level driver integration for radio PHY, network stack, timers, UART
